Portalis (github.com/SKUF666/minecraft-packs) is free and open-source software under the MIT License. Only Portalis.exe built from this repository by its GitHub Actions workflow (.github/workflows/build.yml) is submitted for signing. Binaries from other sources are never signed.

Team roles

Committers and reviewers: SKUF666

Approvers: SKUF666

Every signing request is approved manually by an approver. All team members use multi-factor authentication for GitHub and SignPath.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. Portalis connects to the internet only for what the user does in it: checking for and downloading its own updates (GitHub), downloading maps, mods and game files the user chooses (their original sources, e.g. Modrinth, CurseForge, Mojang), and — only if the user creates an account — the optional Portalis account features (friends, parties, chat, cloud world backups) on Supabase.
