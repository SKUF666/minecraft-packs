Portalis — бесплатная программа для Windows: ставит карты и сборки модов Minecraft одной кнопкой, скачивает версии игры, помогает играть с друзьями (друзья, пати, чат, свой сервер пати) через Hamachi или Radmin VPN.

English

Portalis is a free Windows app that installs Minecraft maps and modpacks in one click, downloads game versions and lets friends play together (friends, parties, chat, party server).

Подпись программы: Free code signing provided by SignPath.io, certificate by SignPath Foundation — правила подписи.

Portalis не связан с Mojang и Microsoft. Minecraft — товарный знак Mojang AB.
